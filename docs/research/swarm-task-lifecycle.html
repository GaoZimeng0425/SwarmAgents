Task 状态机

事件驱动的真实流转;planning/dispatched/paused 在 UI 归并为 running,interrupted 视作 failed

主轨 (happy path)

  • • pending → running → completed 一条横向主轨
  • • running 由 task.dispatched 进入,task.complete 收尾
  • • completed 是终态,不再回到执行

阻塞可恢复

  • • 权限确认 / 向人提问 → awaiting_user
  • • 用户应答后 resolved,回到 running
  • • 此态仍在飞行中,可被取消

终止 & 归并

  • • 失败 / 取消 / 重启中断三类终止态
  • • schema 另有 planning·dispatched·paused → UI 归并为 running
  • • interrupted 由重启标记,UI 视作 failed 呈现
